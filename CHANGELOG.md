# Changelog

## 1.0.1 - 2026-09-08

### Fixed

- Load the Files integration as a classic browser script so it runs correctly when registered through Nextcloud's `Util::addScript` API.

## 1.0.0 - 2026-08-27

### Added

- Fresh read-only public link creation for selected files and folders.
- Unlimited selection at the app level with 100-item internal batches.
- System share sheet handoff and copy fallback.
- Full rollback on partial creation failure and cancellation cleanup.
- Nextcloud public-sharing, password, and expiration policy handling.
- Korean localization.
